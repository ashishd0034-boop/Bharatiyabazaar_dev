How Rebirth Works (Validated Rules)

1
Pool completes at 255 positions
254 downline positions + 1 root position = 255 total. When all are filled, your pool cycle is complete.
2
4 rebirth IDs are generated
Rebirth IDs are generated at AutoPool Levels 4, 5, 6, and 7 — one at each level. They are generated as each level completes, not all at pool completion.
3
Rebirth IDs placed in global AutoPool
Each rebirth ID is placed at the next available breadth-first position in the global AutoPool. Rebirth IDs do NOT create a separate tree. They join the same global tree.
4
Rebirth ID economics
Rebirth IDs generate the same AutoPool economics as purchased IDs: cash at L1–L3, rebirth IDs at L4–L7, vouchers at L5–L7.
5
Rebirth IDs do NOT get MY SYSTEM or ACB
Rebirth IDs have no MY SYSTEM tree, no MY SYSTEM earnings, and no ACB status. They participate only in the global AutoPool.
6
Rebirth ID withdrawal rule
Rebirth ID earnings become withdrawable only when the owner's MAIN ID achieves ACB status. Rebirth IDs cannot achieve ACB themselves.
7
Rebirth IDs generate further rebirths
Each rebirth ID can generate its own rebirth IDs when its L4–L7 fill. This creates an exponential growth pattern through the global AutoPool.
