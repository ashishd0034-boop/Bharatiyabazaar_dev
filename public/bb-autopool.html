How AutoPool Works

1
Breadth-first auto-placement
All IDs — purchased MAIN, SUB, and rebirth — are placed automatically in the global AutoPool using breadth-first positioning based on entry order.
2
Cash at Levels 1–3
Rs.300 + Rs.300 + Rs.200 = Rs.800 per complete pool cycle. Pay-Once Rule applies: Level 1–3 cash is paid only once per ID across AutoPool and MY SYSTEM.
3
Rebirth IDs at Levels 4–7
Each of Levels 4, 5, 6, and 7 generates 1 rebirth ID when complete. Rebirth IDs join the next free global position — they do NOT create a separate tree.
4
Product vouchers at Levels 5–7
Rs.200 voucher at each of Levels 5, 6, and 7. Total Rs.600 in vouchers per pool cycle.
5
Rebirth ID economics
Rebirth IDs earn the same AutoPool economics (cash L1–L3, rebirths L4–7, vouchers L5–7) but do NOT get MY SYSTEM placement or ACB status.
6
Rebirth withdrawal rule
Rebirth ID earnings become withdrawable only when the owner's MAIN ID achieves ACB status.
7
ACB is earned in MY SYSTEM
AutoPool placement is automatic. ACB status is achieved only through MY SYSTEM (1 LEFT + 1 RIGHT direct referral).
