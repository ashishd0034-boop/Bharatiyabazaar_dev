How AutoPool Works

1
Breadth-first auto-placement
All IDs — purchased MAIN, SUB, and rebirth — are placed automatically in the global AutoPool using breadth-first positioning. Each ID receives a global position number based on entry order.
2
Cash at Levels 1–3
Rs.300 + Rs.300 + Rs.200 = Rs.800 per complete pool cycle. Pay-Once Rule applies: Level 1–3 cash is paid only once per ID across AutoPool and MY SYSTEM.
3
Rebirth IDs at Levels 4–7
Each of Levels 4, 5, 6, and 7 generates 1 rebirth ID when complete. Rebirth IDs are placed at the next available position in the global AutoPool. They do NOT create a separate tree.
4
Product vouchers at Levels 5–7
Rs.200 voucher at each of Levels 5, 6, and 7. Total Rs.600 in vouchers per pool cycle. Vouchers are issued at AutoPool Levels 5, 6, and 7 only.
5
Rebirth ID economics
Rebirth IDs generate the same AutoPool economics as purchased IDs: cash at L1–L3, rebirth IDs at L4–L7, vouchers at L5–L7. However, rebirth IDs do NOT get MY SYSTEM, MY SYSTEM earnings, or ACB status.
6
Rebirth ID withdrawal rule
Rebirth ID earnings become withdrawable only when the owner's MAIN ID achieves ACB status. Rebirth IDs cannot achieve ACB themselves.
7
ACB is earned in MY SYSTEM, not AutoPool
AutoPool placement is automatic. Manual placement applies only in MY SYSTEM. ACB status is achieved through MY SYSTEM (2 direct referrals: 1 Left + 1 Right).
